# CBS (Paramount)

> CBS is the flagship broadcast television network of Paramount (Paramount Skydance
> Corporation, formerly Paramount Global), covering CBS Entertainment, CBS News,
> CBS Sports and the CBS owned-and-operated stations, and feeding Paramount+.
> CBS publishes no developer portal, no OpenAPI, no AsyncAPI, no GraphQL schema and
> no llms.txt of its own. This file is generated by API Evangelist from probed
> evidence, not published by CBS. Two first-party machine-readable surfaces are live
> and anonymously reachable and are described below; everything else in Paramount's
> API estate — partner distribution, syndication, and the EyeQ / Conduit advertising
> stack — is private with no public contract.

## APIs

- [CBS Sports Fantasy API](https://www.cbssports.com/fantasy/): REST, base
  `https://api.cbssports.com/fantasy`. Version 3.0, selected with the `version` query
  parameter. `response_format=json` or `xml` — XML is the default, and the `Accept`
  header is ignored. `GET /fantasy/sports` and
  `GET /fantasy/players/list?sport=football` answer with no credential. League-scoped
  resources (`/league/details`, `/league/teams`, `/league/schedules`,
  `/league/rosters`, `/league/scoring/categories`, `/league/scoring/live`,
  `/league/draft/results`) require a `league_id` and an access token CBS issues only
  to a member of a CBS Sports fantasy league. The developer portal that documented
  this API, `developer.cbssports.com`, no longer resolves.
- [CBS News RSS Feeds](https://www.cbsnews.com/rss/): RSS 2.0, base
  `https://www.cbsnews.com/latest/rss`. Unauthenticated GET per section —
  `/main`, `/us`, `/world`, `/politics`, `/technology`, `/entertainment`.

## Automated-access policy

- `https://api.cbssports.com/robots.txt` — `User-agent: *` / `Disallow: /`. The API
  host refuses all robots.
- `https://www.cbssports.com/robots.txt` — `User-agent: GPTBot` / `Disallow: /`.
- Read both before automating anything against these hosts.

## Specs

- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, Protobuf, WSDL or JSON Schema is
  published by CBS or Paramount at any location probed.
